## **[5.1.0]**

### **Release Notes**

This release makes configuring non-default domains simpler with the new `config.source.general.baseDomain` setting, which lets you configure all domains via a single value. The screen wake lock is now renewed after the browser has released it. Configuration related warning events during player setup have been improved.

### **Changelog**

### Added

- new config setting `config.source.general.baseDomain`, allowing configuring all domains via a single value

### Fixed

- screen wake lock not being renewed after it has been released by the browser

### Improved

- configuration related warning events during player setup
